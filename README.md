# RateThatSite ⭐️
Una piattaforma web per cercare, leggere e aggiungere recensioni su qualsiasi sito web.

## Tecnologie Utilizzate
* HTML, CSS (Font: Poppins)
* Python (Flask)
* SQLite (Database)

## Come avviare il progetto in locale
1. Assicurati di avere Python installato.
2. Esegui il file `setup_db.py` per inizializzare il database.
3. Avvia il server eseguendo `python app.py`.
4. Apri il browser all'indirizzo `http://127.0.0.1:5000`
